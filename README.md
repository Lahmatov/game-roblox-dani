# Прятки за Кубок 🏆

Игра для Roblox: прятки на стадионе «Спортинга». Один водящий ищет, до 22 игроков прячутся
и ищут **Кубок мира**. Кто найдёт Кубок, тот должен забить его в ворота!

Все правила описаны в [GAME_DESIGN.md](GAME_DESIGN.md).

## Как поиграть в Roblox Studio

1. Скачай файл [`build/PryatkiZaKubok.rbxl`](build/PryatkiZaKubok.rbxl) и открой его в Roblox Studio.
2. Стадион строится сам, когда игра запускается, поэтому в редакторе сначала пусто — это нормально.
3. Для игры нужно минимум **2 игрока**. В Studio открой вкладку **Test**, выбери
   **Clients and Servers**, поставь **2 Players** (или больше) и нажми **Start**.
   Откроются окна сервера и игроков.
4. Чтобы игра работала с друзьями, нажми **File → Publish to Roblox**.
   В **Game Settings → Places** можно поставить «Max Players» = 23 (1 водящий + 22 прячущихся).
5. Чтобы монеты и формы сохранялись, в **Game Settings → Security** включи
   **Enable Studio Access to API Services**.

## Управление

| Кнопка | Что делает |
|---|---|
| **Q** или кнопка «Рывок» | ускорение (раз в 30 секунд) |
| **F** или кнопка «Мяч» | пнуть мяч туда, куда смотрит камера. Попал в водящего — он замирает на 2 секунды |
| «Хочу водить!» | в лобби: записаться в водящие |
| «Магазин» | купить и надеть футбольную форму за монеты |

## Формы с рисунком

Формы «Зелёные львы», «Красные звёзды», «Ночная молния» и «Золотая с короной» нарисованы
по дизайну Дани. Готовые шаблоны одежды Roblox лежат в [`assets/kits/`](assets/kits/),
как они выглядят — в [`assets/kits/preview.png`](assets/kits/preview.png).

Чтобы рисунок появился в игре (это надо сделать один раз, лучше вместе со взрослыми):

1. Открой [create.roblox.com](https://create.roblox.com) → **Creations → Development Items → Decals**
   и загрузи `lions_shirt.png`, `lions_pants.png` и остальные (загрузка картинок бесплатная).
2. У каждой загруженной картинки скопируй её номер (Asset ID).
3. Впиши номера в `src/shared/Config.luau` в `ShirtTemplate` и `PantsTemplate` нужной формы.

Пока номер равен 0, форма показывается просто цветом. Перерисовать шаблоны: `python3 tools/make_kits.py`.

## Где что менять

Все числа — время раунда, скорость, цены форм, сколько монет дают — лежат в одном файле:
[`src/shared/Config.luau`](src/shared/Config.luau).

| Файл | Что внутри |
|---|---|
| `src/server/StadiumBuilder.luau` | строит стадион: поле, ворота, трибуны, туннель, раздевалки, табло, тюрьму, лобби |
| `src/server/RoundManager.luau` | раунды: выбор водящего, прятки, поимка, тюрьма, победа |
| `src/server/Trophy.luau` | Кубок мира: где спрятан, подсказки, подобрать, уронить |
| `src/server/Statues.luau` | футболисты-статуи, которые оживают |
| `src/server/Abilities.luau` | рывок и мяч |
| `src/server/Economy.luau` | монеты, магазин, сохранение |
| `src/client/Main.client.luau` | экран игрока: таймер, кнопки, магазин |

## Для разработчиков

Проект собирается [Rojo](https://rojo.space):

```sh
rojo build default.project.json -o build/PryatkiZaKubok.rbxl   # собрать файл игры
rojo serve                                                       # живая синхронизация со Studio
```

Автоматический плейтест: боты играют 4 раунда в имитации Roblox и проверяют правила
(поимка, тюрьма, освобождение, Кубок, гол, статуи, мяч, рывок, магазин, сохранение):

```sh
npm install
npm test
```

Имитация проверяет логику игры, но не настоящую физику и не внешний вид, поэтому после
изменений стоит ещё и поиграть в Studio.
