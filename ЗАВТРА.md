# Что сделать на компьютере

Код игры готов. Вот что можно сделать только на компьютере или в других программах.
Пункты расставлены по порядку.

## 1. Сыграть в Studio (≈15 минут)
- [ ] Открыть `build/PryatkiZaKubok.rbxl` в Roblox Studio и нажать **Play**. Боты включены, так что можно играть одному.
- [ ] Посмотреть то, что автоматический плейтест проверить не может (в нём нет настоящих стен и физики):
  - забегаются ли игроки и боты по пандусам на трибуны, проходят ли в туннель и раздевалки;
  - залезают ли по лестнице на крышу;
  - не застревают ли боты о стены (если застревают — пришли скриншот);
  - нормально ли ходят ожившие статуи;
  - не слишком ли темно на стадионе (настраивается в `StadiumBuilder.luau`, `setupLighting`).
- [ ] Проверить игру с людьми: **Test → Clients and Servers → 2 Players → Start**.
- [ ] Если что-то не так — сделать скриншот и написать, что случилось.

## 2. Формы с рисунком (≈10 минут)
- [ ] На [create.roblox.com](https://create.roblox.com) открыть **Creations → Development Items → Decals** и загрузить 8 картинок из `assets/kits/`:
  `lions_shirt.png`, `lions_pants.png`, `stars_shirt.png`, `stars_pants.png`,
  `night_shirt.png`, `night_pants.png`, `gold_shirt.png`, `gold_pants.png`.
- [ ] Переписать номер (Asset ID) каждой картинки и прислать их Claude, либо самому вписать в
  `src/shared/Config.luau` в `ShirtTemplate` / `PantsTemplate`.

## 3. Картинки через Gemini (по желанию)
- [ ] На [aistudio.google.com](https://aistudio.google.com) нажать **Get API key**. Для генерации картинок может понадобиться включить оплату.
- [ ] Добавить ключ в настройках облачной среды (меню среды в заголовке сессии → **Edit**) как переменную **`GEMINI_API_KEY`** и начать новую сессию. Тогда Claude сам нарисует иконку, Кубок и новые формы.
- [ ] Или нарисовать вручную по промпту из чата и прислать картинки в полном размере. Иконка — 512×512 или больше.

## 4. Публикация
- [ ] **File → Publish to Roblox**.
- [ ] **Game Settings → Security**: включить **Enable Studio Access to API Services**, чтобы сохранялись монеты и формы.
- [ ] **Game Settings → Places → Max Players = 23** (1 водящий + 22 прячущихся).
- [ ] На create.roblox.com заполнить анкету о содержании игры (**Experience Questionnaire**). Без неё игру не откроют для всех.
- [ ] Загрузить иконку и пару скриншотов (**Thumbnails**).

## 5. Перед тем как зарабатывать
- [ ] Переименовать названия настоящих клубов и турниров: «Спортинг», «Реал», «Барса», «Кубок мира». Например в «Зелёные», «Белые», «Золотой Кубок». Иначе игру могут заблокировать за чужие товарные знаки.
- [ ] Придумать, что продавать (лучше красоту, а не силу): например Game Pass «Золотая форма» или «VIP-ложа».
- [ ] Создать Game Pass на create.roblox.com и прислать его номер Claude: покупку в игре он подключит сам.
- [ ] Обмен Robux на деньги (DevEx): нужно быть старше 13 лет, пройти проверку документов и накопить 30 000 заработанных Robux.
